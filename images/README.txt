Place your images in this folder using these exact names:

1) profile.jpg   -> Your hero/profile photo
2) project1.jpg  -> Project preview image (used in featured project cards)
3) cert1.jpg     -> Certificate image 1
4) cert2.jpg     -> Certificate image 2

How to replace:
- Keep the same filenames above, or
- If you use different names, update the paths in index.html (src and data-image attributes).

Recommended image sizes:
- profile.jpg: 900x900 or larger (square)
- project1.jpg: 1280x720 or larger (landscape)
- cert1.jpg / cert2.jpg: 1600x1100 or larger
